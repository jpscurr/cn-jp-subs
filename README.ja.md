# 字幕ジェネレーター

センテンスマイニング用の中国語・日本語字幕を作ります。生成した `.srt` はそのまま asbplayer にドラッグできます。

YouTube のリンクを渡すだけです。投稿者がその言語の字幕を自分で付けていれば、それをそのまま使います——
無料で、即座で、しかも音声と完全に一致しています。無ければ音声をダウンロードし、Groq の Whisper で文字起こしします。
どちらの経路でも出力はきれいに整形された `.srt` で、各字幕の下に読み仮名の行と英訳の行を追加することもできます。

中国語と日本語は出力先ディレクトリが分かれているので、2 つの言語の動画が混ざることはありません。

## インストール

```
pip install -r requirements.txt
```

ffmpeg と ffprobe が PATH に必要です（`winget install Gyan.FFmpeg`）。

そのあと Groq の API キーを入れます。画面の「設定」から入力するか、環境変数 `GROQ_API_KEY` を設定してください。
環境変数のほうが優先されます。キーは <https://console.groq.com/keys> で無料で取得できます。
キーは `config.json` に保存されます。このファイルは gitignore 済みで、ソースコードに書き込まれることはありません。

キーが無くても動きますが、その場合は動画に元から字幕が付いているものに限られます。

## 実行

**ウェブ画面** —— `start.bat` をダブルクリック、または：

```
python app.py
```

リンクを 1 つ以上（プレイリストも可）貼り付けて「生成開始」を押します。タスクは 1 つずつ順番に処理され、
ログはリアルタイムで流れます。タスクをクリックするとログが開き、完了したファイルをクリックすると
そのままページ内で 1 行ずつ読めます。

**コマンドライン**

```
python cn.py                        クリップボードのリンクを監視
python cn.py <リンク> [<リンク> ...]  直接処理、プレイリストは自動展開
python cn.py --ui                   ウェブ画面を起動
python cn.py --lang ja <リンク>       今回だけ日本語として処理
```

その他のオプション：`--reading` / `--no-reading`、`--translate` / `--no-translate`、
`--model 名前`、`--turbo`、`--force`（「処理済み」の記録を無視）。

## 設定項目

| 設定 | 内容 |
| --- | --- |
| 言語 | 中国語または日本語。切り替えると出力先ディレクトリ、プロンプト、読み仮名の方式、1 行の文字数がまとめて切り替わります。 |
| Whisper モデル | `whisper-large-v3` のほうが正確。`-turbo` は約 4 倍速く安価ですが、細かいニュアンスに弱いです。 |
| 字体 | 出力を簡体字か繁体字に統一します。Whisper の出力は簡繁が安定しないので、統一する価値があります。中国語のみ。 |
| 読み仮名の方式 | 中国語はピンイン。日本語はひらがなかローマ字を選べます。 |
| 1 行の最大文字数 | 超えたら句読点の位置で改行します。中国語は既定 26、日本語は 24。 |
| 分割の長さ | 1 リクエストで送る音声の秒数。アップロードがタイムアウトするなら小さくします。 |
| 同時アップロード数 | 同時に文字起こしする分割数。速くしたいなら増やし、レート制限に当たるなら減らします。 |
| 英訳の行 | 整形済みの字幕にもう一度翻訳をかけます。文脈付きでバッチ処理します。 |
| 自動生成字幕を許可 | 人手の字幕が無いとき、YouTube の機械字幕を使うかどうか。たいてい自前の文字起こしより悪いので既定はオフ。 |

## 画面でできること

字幕を作ったら終わり、ではありません。作ったあとにこう使えます。

- **Insights**（プレビュー内、または `i`）——その回で繰り返し出てくる語を、
  読みと回数つきで一覧します。中国語なら漢字単体の一覧も出ます。上の数字は
  行数・長さ・毎分の文字数・異なり漢字数、そしてざっくりした難度の目安です。
  多聴の素材を選ぶとき、十分間見てみるより早く判断できます。
  語をクリックすると、その語を含む行だけに絞り込まれます。
- **Look up**（`l`）——これまでに作った全字幕から語を探します。どのファイルの
  何秒かが出るので、クリックすればその行へ飛べます。
- **Anki 書き出し**（`Anki` ボタン）——タブ区切りのテキストで、順に
  原文 / 読み / 訳 / 出典。Anki の「ファイルをインポート」でそのまま読めます。
- **テーマ**（設定、または `t` で順送り）——七色。「言語に合わせる」を選ぶと、
  中国語は朱色、日本語は藍色になります。
- **背景**（設定）——既定は回路基板で、光る点が線を辿って流れます。自分の画像や
  無地にも変えられます。「アニメーション」を切れば画面は完全に静止し、
  非力なマシンでは一番軽くなります。

`?` で全ショートカットが出ます。

## ディレクトリ構成

```
app.py              ウェブサーバーとタスクキュー
cn.py               コマンドラインの入口、クリップボード監視
web/                画面（HTML 1 つ、CSS 1 つ、JS 1 つ）
cnsubs/
  languages.py      各言語の定義。言語を足すならここに 1 件追加するだけ
  config.py         設定。config.json と GROQ_API_KEY から読み込み
  pipeline.py       yt-dlp、ffmpeg、Whisper、そして全体の流れ
  srt.py            SRT / VTT の解析と生成
  text.py           整形、簡繁変換、改行、読み仮名
  translate.py      任意の英訳行
  analyze.py        語彙・漢字の頻度、話速、難度
  library.py        出力フォルダ全体の検索（キャッシュ付き）
test_offline.py     ネットもキーも無しで実行できます
```

## 字幕の質に効いている細かい点

センテンスマイニングにとって重要な処理がいくつかあるので、その理由を書いておきます：

- **各分割の時間オフセットは計算値ではなく実測値です。** 切れ目はフレーム境界に落ちるので、
  指定した秒数ぴったりにはなりません。だから分割ごとに実際の長さを測ります。すべて等長だと
  仮定すると、動画が長いほど字幕のずれが分割ごとに積み上がっていきます。
- **Whisper の定型ハルシネーションを除去します** —— 無音部分に湧いてくる「字幕由…提供」「請不吝點贊訂閱」
  「ご視聴ありがとうございました」といった締めの文句や、デコードのループに陥って
  同じフレーズを最後まで繰り返す場合です。
- **字幕どうしは重ならず、長さ 0 の字幕も出しません。** どちらもうまく扱えないプレイヤーがあります。
- **ピンインは jieba で分かち書きしてから変換します。** だから「了」は `liǎo` ではなく `le` になり、
  「行」も正しい読みが選ばれ、「不」「一」の変調も正しく処理されます。単語単位でまとめること自体、
  音節をばらばらに並べるより読みやすくなります。
- **日本語の仮名は元のカタカナを保ちます。** エピソード が えぴそーど に潰れることはありません。
- **日本語には簡繁変換をかけません。** かけると日本語の漢字が壊れるためです。
