# 字幕生成器

为句子挖掘准备的中文、日文字幕，生成后可以直接拖进 asbplayer。

给它一个 YouTube 链接就行。上传者要是自己发布了对应语言的字幕，就直接用那份——
免费、即时，而且和原话完全对得上；没有的话就下载音频，交给 Groq 的 Whisper 转写。
两条路的结果都是一个清洗过的 `.srt`，还可以选择在每条字幕下面加一行注音、一行英文。

中文和日文各自有独立的输出目录，两种语言的视频不会混在一起。

## 安装

```
pip install -r requirements.txt
```

ffmpeg 和 ffprobe 需要在 PATH 里（`winget install Gyan.FFmpeg`）。

然后填一个 Groq API 密钥——在界面的「设置」里填，或者设置环境变量 `GROQ_API_KEY`，
环境变量的优先级更高。密钥可以在 <https://console.groq.com/keys> 免费申请。
密钥保存在 `config.json` 里，该文件已被 gitignore 忽略，绝不会写进源代码。

没有密钥也能用，只是仅限于视频本身自带字幕的情况。

## 运行

**网页界面** —— 双击 `start.bat`，或者：

```
python app.py
```

粘贴一个或多个链接（播放列表也行），点「开始生成」。任务一个接一个地跑，
日志实时滚动；点任务可以展开日志，点已完成的文件可以直接在页面里逐条阅读。

**命令行**

```
python cn.py                        监听剪贴板里的链接
python cn.py <链接> [<链接> ...]     直接处理，播放列表会自动展开
python cn.py --ui                   启动网页界面
python cn.py --lang ja <链接>        这一次按日文处理
```

其他参数：`--reading` / `--no-reading`、`--translate` / `--no-translate`、
`--model 名称`、`--turbo`、`--force`（忽略「已处理过」的记录）。

## 设置说明

| 设置项 | 作用 |
| --- | --- |
| 语言 | 中文或日文。切换语言会同时切换输出目录、提示词、注音方式和每行字数。 |
| Whisper 模型 | `whisper-large-v3` 更准；`-turbo` 快约四倍、更便宜，但在细微差别上弱一些。 |
| 字形 | 强制统一输出简体或繁体。Whisper 输出的简繁很不稳定，强制统一是值得的。仅中文有此项。 |
| 注音方式 | 中文是拼音；日文可选平假名或罗马字。 |
| 每行最多字数 | 超过就在标点处断开。中文默认 26，日文默认 24。 |
| 每段长度 | 每次请求发送的音频秒数。上传老是超时就调小。 |
| 并发上传数 | 同时转写的段数。想快就调大，遇到限流就调小。 |
| 英文行 | 对整理好的字幕再跑一遍翻译，按批处理并带上下文。 |
| 接受自动生成的字幕 | 没有人工字幕时是否使用 YouTube 的机器字幕。通常还不如自己转写，所以默认关闭。 |

## 目录结构

```
app.py              网页服务和任务队列
cn.py               命令行入口，以及剪贴板监听
web/                界面（一个 HTML、一个 CSS、一个 JS）
cnsubs/
  languages.py      各语言的定义，加一门语言只需在这里添一条
  config.py         设置，来自 config.json 和 GROQ_API_KEY
  pipeline.py       yt-dlp、ffmpeg、Whisper，以及整个流程
  srt.py            SRT / VTT 的解析与生成
  text.py           清洗、简繁转换、断行、注音
  translate.py      可选的英文行
test_offline.py     不联网、不需要密钥即可运行
```

## 几个影响字幕质量的细节

有几处做法对句子挖掘挺关键，这里说明一下原因：

- **每段的时间偏移是实测的，不是算出来的。** 切割点落在帧边界上，而不是精确落在
  要求的那一秒，所以每段都要实测时长。如果假定每段刚好等长，视频越长，字幕就会
  一段比一段偏得更多。
- **过滤掉 Whisper 的固定幻觉** —— 静音处冒出来的「字幕由…提供」「請不吝點贊訂閱」
  「ご視聴ありがとうございました」这类结束语，以及它卡进解码死循环时
  同一个短语重复到底的情况。
- **字幕之间不重叠，也没有零长度的字幕**，有些播放器处理不好这两种情况。
- **拼音先用 jieba 分词再转换**，所以「了」会读成 `le` 而不是 `liǎo`，「行」能选对读音，
  「不」「一」的变调也能正确处理。按词分组本身也比一个个音节散着排更好读。
- **日文假名保留原有的片假名**，エピソード 不会被压成 えぴそーど。
- **对日文不做简繁转换**，否则会把日文汉字弄坏。
